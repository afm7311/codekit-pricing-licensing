## 谁该买 CodeKit，谁买了会闲置

做 WordPress 主题、营销落地页的人最对口。给 Laravel 或 Rails 项目写前端资源也一样，Sass 编译、JS 合并、图片压缩这些活，在 CodeKit 里是勾选框而不是配置文件。接外包的工作室还有一层好处，项目配置能跟着 Git 走，每个项目同一套设置，换人接手不用重新讲一遍怎么构建。

有几类人我建议直接跳过。主力做 Next.js、Nuxt 或 SvelteKit 的，官方自己说明了它不是这些框架 dev server 的替代品，继续用框架自带工具链就行。Windows 用户没得选，CodeKit 只覆盖 Mac。一年只编译几次的人装了也是闲置。已经有一套顺手的命令行脚本、又不介意敲命令的人，同样没必要花这 39 美元。还有一类，指望它“买了就自动把网站做好”的，它管的是构建流程，不生成页面。

## 优点，以及几个要提前知道的限制

买断制在 Mac 工具里不算常见，这是它最实在的优点。试用给足 10 天而且全功能，不用先付钱才能看到界面。配置能共享，团队里每个人的构建结果一致。AI agent 集成不是概念图，是能跑命令的 CLI。付款走 Stripe 的嵌入式表单，卡号不经过作者自己的服务器，数据库里也不存。

限制同样明确，买之前得接受：

- 不退款。官网写明所有销售最终有效，试用版就是给你评估用的，别抱着“先买再退”的打算。
- 更新只有 13 个月。想一直拿新版本得续费，这是一笔额外的钱，官方单独定价。
- 3 台 Mac 是上限，前提还是你本人在用。同事要用就按人头加授权，几个人共用一个码不合规。
- 试用到期不是彻底锁死，而是转到只读模式。编译和构建还能跑，设置改不了。这个设计挺宽松，也意味着你没法靠它长期干活。
- 中文网络上关于它的独立评测不多，我这次没找到可以引用的第三方评分，上面这些判断都基于官方条款和功能说明。

**CodeKit 是订阅制吗？**
